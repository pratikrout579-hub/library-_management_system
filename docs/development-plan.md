# Agile-style development plan

| Milestone | Deliverable | Outcome |
|---|---|---|
| 1 | Foundation | CMake layout, schema, seed data, static pages |
| 2 | Identity | Password hashing, session tokens and role checks |
| 3 | Collection | Book/student CRUD and catalogue search |
| 4 | Circulation | Requests, approval, direct issue, returns and fines |
| 5 | Visibility | Reports, activity history, responsive polish |
| 6 | Quality | Test cases, documentation and Linux device driver integration |

Each milestone is separately demonstrable. This makes a 10-minute presentation easy: explain a user story, show the associated endpoint, then show the corresponding database state.
